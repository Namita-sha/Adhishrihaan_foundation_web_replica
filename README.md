# Adhishrihaan Foundation Website

A responsive website replica of the Adhishrihaan Foundation website.

## Technologies Used
- HTML
- CSS
- Bootstrap 5

## Features
- Responsive navigation bar
- Focus area cards
- Events section
- Footer

## How to Run
Open `index.html` in your browser or use VS Code Live Server.
